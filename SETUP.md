# Creating a New Trip Journal

This guide explains how to create a new trip journal using this template.

## Quick Start

### 1. Create New Repository

On GitHub, click **"Use this template"** to create a new repository for your trip.

```bash
git clone <your-new-repo-url>
cd <your-new-repo>
npm install
```

### 2. Configure Your Trip

Edit the following files:

#### Frontend Config: `src/config/trip.config.ts`

```typescript
export const tripConfig = {
  // Change app title
  tripName: "My Japan Trip 2026",

  // Subtitle displayed above the main title
  tripSubtitle: "Japan 2026",

  // Menu links
  links: {
    googleSheet: 'https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID',
    googleMap: 'https://maps.app.goo.gl/YOUR_SHARED_MAP',
    github: 'https://github.com/YOUR_USERNAME/YOUR_REPO',
  },

  // Add/remove currencies as needed
  currencies: [
    { code: 'JPY', symbol: '¥', label: '日圓' },
    { code: 'TWD', symbol: 'NT$', label: '台幣' },
  ] as const,

  defaultCurrency: 'JPY',

  // Customize expense categories
  categories: [
    { code: 'Food', label: '餐飲' },
    { code: 'Transport', label: '交通' },
    // ... add more as needed
  ] as const,

  // Match your Google Sheet tab names
  sheetNames: {
    itinerary: '行程',
    expenses: '記帳',
    todos: '待辦',
    attractions: '景點規劃',
    navigation: '導航',
    food: '美食推薦',
    journey: '旅程介紹',
    chat: 'AI秘書對話',
  },
};
```

#### Backend Config: `gas/Code.js`

```javascript
var CONFIG = {
  pageTitle: 'My Japan Trip 2026',

  // Match your Google Sheet tab names
  sheetNames: {
    itinerary: '行程',
    expenses: '記帳',
    todos: '待辦',
    attractions: '景點規劃',
    navigation: '導航',
    food: '美食推薦',
    journey: '旅程介紹',
    chat: 'AI秘書對話'
  }
};
```

Editor permissions and Gemini API keys are stored in Google Apps Script Script Properties, not in source code:

```javascript
PropertiesService.getScriptProperties().setProperty(
  'AUTHORIZED_EDITORS',
  'your-email@gmail.com,partner@gmail.com'
);

PropertiesService.getScriptProperties().setProperty(
  'GEMINI_API_KEY',
  'your-gemini-api-key'
);
```

#### HTML Title: `src/index.html`

```html
<title>My Japan Trip 2026</title>
```

### 3. Create Google Sheet

Create a new Google Sheet with these tabs:

| Tab Name | Columns |
|----------|---------|
| 行程 | Day, Date, Weekday, City, Content, Transport, Ticket, Link, Hotel |
| 記帳 | Timestamp, Item, Amount, Currency, Category |
| 待辦 | Section, Item, Detail, Deadline, Done |
| 景點規劃 | Day, Title, Content |
| 導航 | Day, Name, Latitude, Longitude |
| 美食推薦 | Day, City, PriceLevel, Content, UpdatedAt |
| 旅程介紹 | Type, Content, UpdatedAt |
| AI秘書對話 | Timestamp, Question, Answer |

For the `待辦` tab:

- Use column A rows with an empty Item cell as priority section headings.
- Use rows with column B filled as todo items.
- Use column E as a checkbox boolean for completion status.
- Add a `【重要連結彙整】` section marker if you keep reference links below the todos; the app stops rendering todo items after that marker.

For the `旅程介紹` tab, use `intro`, `closing`, and `city:<city name>` values in the `Type` column.

### 4. Create Google Apps Script Project

```bash
# Login to clasp (first time only)
clasp login

# Create new GAS project linked to your Sheet
clasp create --type webapp --parentId <your-sheet-id>
```

This will create a new `.clasp.json` file with your project's `scriptId`.

### 5. Deploy

```bash
npm run deploy
```

### 6. Set Up Auto-Deploy (Optional)

For GitHub Actions auto-deploy, add these secrets to your repository:

| Secret | Description |
|--------|-------------|
| `CLASPRC_JSON` | Contents of `~/.clasprc.json` (your clasp credentials) |
| `DEPLOYMENT_ID` | Your GAS deployment ID (from `clasp deployments`) |
